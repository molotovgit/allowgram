# Allowgram 7.2.8.4 for Windows x64

This release corrects clipped and cramped allow-list ID fields. Each row uses
Telegram's native input height and floating-label spacing. Remove aligns with
the editable text. Use the plus buttons for additional users or groups/channels;
scroll normally to reach validation messages and Save and continue.

The numeric-only ID policy, stored allow-list and allowed-bot Mini App protections
are unchanged. Upgrading does not require logging out or rebuilding your list.
The installer is unsigned, installs per user and preserves account data on
uninstall. Verify its SHA-256 against the accompanying SHA256SUMS.txt.

The package includes the installer, portable ZIP and corresponding source
archive. Build metadata identifies the source commit. See the accompanying
validation evidence for the actual build, UI regression and isolated installation
results. No live account, message or permission-grant testing is implied.

See [setup instructions](allowgram/allow-list.md), [test scope](allowgram/testing.md)
and [upstream licensing](../LEGAL).
